# Chauhan Photo Studio

Website for Chauhan Photo Studio, Rohru, Himachal Pradesh.

## Local preview

```sh
python3 -m http.server 4173 --directory public
```

Visit <http://localhost:4173/>. The site is plain HTML, CSS and JavaScript, with no build step.

The hero artwork is illustrative. The Rohru landscape images in `assets/` were supplied by the studio; copies used by the website live in `public/assets/`.
